# Raccoonbox WoW Addons

Addons for the World of Warcraft 1.12 (vanilla) client. Collected by Raccoonbox.

*Not affiliated with or endorsed by Blizzard Entertainment.*

## Install

1. Click **Download** next to the addon you want below. Each addon is its own small zip.
2. Unzip it and put the folder into your game's `Interface/AddOns/` folder.
3. Restart the game and tick the addons in the **AddOns** list on the character select screen.

## Addons

### Made by Raccoonbox

| Addon | What it does | |
|---|---|---|
| **WindowToggle_Raccoonbox** | Minimap button that switches the game between a maximised window and a small window (1024 wide, same shape as your screen). **Right-click** to pick the small window size from a menu. Drag to move. `/wt size 1280x720` sets a custom size, `/wt size auto` goes back to default, `/wt list` shows accepted sizes. | [Download](https://github.com/raccoonbox/wow-addons/releases/latest/download/WindowToggle_Raccoonbox.zip) |
| **HideButtons_Raccoonbox** | Hide any minimap button: hover over it and type `/hidebtn`. It stays hidden. `/hidebtn list`, `/hidebtn clear`. | [Download](https://github.com/raccoonbox/wow-addons/releases/latest/download/HideButtons_Raccoonbox.zip) |
