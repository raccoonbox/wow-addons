# TotemTimers_Raccoonbox: changes

Based on TotemTimers Enhanced 1.1 by LYQ (originally by Grumpey / Zulah). This list covers only what Raccoonbox changed.

## Raccoonbox 1.0.0

### New
- **Party Totems:** shows the totems that other shamans in your party have dropped, with timers. Each party shaman gets a row of icons below your own TotemTimers buttons. Requires Nampower. Turn it on or off with `/ttparty on` and `/ttparty off`.

### Technical
- Renamed to `TotemTimers_Raccoonbox` so it can be installed alongside the original.
- Adds the shared Raccoonbox welcome message (`RaccoonboxWelcome.lua`).
