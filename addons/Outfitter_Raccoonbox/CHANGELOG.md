# Outfitter_Raccoonbox: changes

Based on [Outfitter 1.5.3](https://github.com/sica42/Outfitter). This list covers only what Raccoonbox changed.

## Raccoonbox 1.0.0

### New
- **Outfit menu at cursor** key binding: opens the outfit menu right under your mouse, so you can switch outfits without going to the minimap button. Set it in **Key Bindings → Outfitter**. The menu always stays on screen.

### Technical
- Renamed to `Outfitter_Raccoonbox` so it can be installed alongside the original. Texture paths updated to the new folder name.
- Adds the shared Raccoonbox welcome message (`RaccoonboxWelcome.lua`).
